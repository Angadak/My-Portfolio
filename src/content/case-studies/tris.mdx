## Problem

Operations staff needed reliable, secure access to train tracking data and reports, with strong authentication on shared terminals.

## What I built

- REST APIs for train tracking, user management and facial recognition, documented with Swagger.
- A modular ASP.NET Core MVC dashboard with customisable reports.
- Face-recognition login integrated into the dashboard sign-in flow.

## Architecture

ASP.NET Core Web APIs, documented with Swagger, sit over a MySQL database through Entity Framework. The MVC dashboard uses those APIs for tracking data and reports, and face recognition is part of the sign-in flow.

## Hard problems

### Face-recognition login that staff actually use

Shared terminals make passwords a weak point, but sign-in still has to be quick at the start of a shift. Face recognition had to fit into the existing login flow without slowing staff down.
