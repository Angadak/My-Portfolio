## Problem

Benefit administrators at large companies needed one place to configure schemes, manage eligibility and review activity, without raising support tickets for routine changes.

## What I built

- Admin screens in Blazor backed by .NET Core services and Entity Framework.
- API integrations between the portal and the services behind it.
- CI/CD pipelines and Azure deployments so releases became routine.

## Hard problems

### Safe releases for a portal clients rely on daily

Administrators at large client companies use the portal for day-to-day work, so a broken release is noticed straight away. Automated pipelines and Azure deployments meant every release went through the same build and deploy steps instead of a manual publish.
